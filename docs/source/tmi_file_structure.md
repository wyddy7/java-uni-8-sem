## Текст

Структура файла с результатами обработки ТМИ
Файлы с результатами обработки ТМИ являются двоичными файлами, содержат последовательность ТМ-записей ниже определённой структуры. Числа представлены в формате прямого порядка байт (старший байт по младшему адресу).

Если поле <Номер Параметра> равно 0xffff, то ТМ-запись является «Cлужебным сообщением».
Время — миллисекунды от начала текущих суток (GMT+3).
Размерность: 1..31 — формат вывода; 32..255 — номер символьной размерности из `dimens.ion`.

Типы служебных сообщений (поле <Тип сообщения>, байт 6):
- 0 — пустая посылка
- 1 — начало сеанса (общая длина записи 32 байта)
- 2 — текущее время
- 3 — конец сеанса (сообщение END!)
- 4 — смена режима (номер режима — целое)
- 5 — смена даты (сутки от 1980 г.)
- 6 — ошибка (номер ошибки — целое)

Номера режима:
0 — недостоверный режим
1 — режим НП
2..8 — режимы ВП

Номера ошибок (пример):
1001, 1003, 1004, 1010

В исходнике также приведены схемы разметки байтов для полезных записей и служебных сообщений, включая поля типа `Point` (переменная длина массива).
