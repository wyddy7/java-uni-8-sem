## Текст

Лабораторные работы (Технологии ЦУП, 2026, 8 семестр)
(К3-83, 84, 85, 86 Б)

Дано:
двоичный ТМ-файл с результатами обработки телеметрической информации борта КА НСЭН «Канопус-В» (“190829_v29854.KNP” – файл содержит последовательность ТМ-записей, структура ТМ-записи дана в Приложении);
XML-файл “KNP-173.14.33.58.dat.xml” с данными о параметрах: соответствие имени и номера параметра, полное имя параметра и текстовые значения параметра;
текстовый файл “dimens.ion”, содержащий соответствие номера размерности (номер строки в файле, нумерация строк с 1) и её текстового значения (каждая физическая размерность занимает 1 строчку, номеру 32 должна соответствовать размерность %).

Требуется:
- написать программу на языке программирования Java;
- разработать структуру для ТМ-записи (TmDat, TmLong, TmDouble, TmCode, TmPoint);
- выбрать структуру (java-класс), в которой сохранить все ТМ-записи в порядке входного файла;
- из созданной структуры выдать в текстовый файл “rez.txt” все заказанные пользователем ТМ-записи в текстовом виде (служебные сообщения не выдавать, пропускать). Каждая текстовая строчка должна содержать следующую информацию:
  - имя параметра,
  - номер параметра,
  - значение (для типа “Point” значение можно не выдавать) с физической размерностью,
  - время – часы:минуты:секунды,миллисекунды (на входе время в миллисекундах от начала суток);
- доработать программу для формирования результата (файла “rez.txt”), отсортированного по имени параметра;
- разбить результат-документ на страницы;
- сформировать в конце документа «Алфавитный указатель» – соответствие имени параметра и номера страницы первого появления параметра;
- определить и вывести на печать различную статистику:
  - S — общее количество ТМ-записей,
  - S_TM — количество полезных ТМ-записей,
  - S_Sluz — количество служебных ТМ-записей (S = S_TM + S_Sluz),
  - S_XML — общее количество параметров борта из XML,
  - Q0_File..Q3_File — количество полезных параметров различных типов значений (S_TM = Q0 + Q1 + Q2 + Q3),
  - и возможно что-то ещё.

Далее в исходнике: приложение со структурой ТМ-записей, типами служебных сообщений (включая «смена режима»), методические указания и пример файла.
