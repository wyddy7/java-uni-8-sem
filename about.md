ШПАРГАЛКА ПО ПРОЕКТУ (Где что лежит)
Главный файл: src/ru/uni/lab/ui/MainFrame.java
Это "пульт управления". Тут собирается всё окно.
1. "Где чтение файлов?" (Самый частый вопрос)
Где: Класс ru.uni.lab.service.DataService, метод loadData.
Как работает:
Читает XML (readXml), строит карту "Номер -> Имя".
Читает dimens.ion (readDimensions), строит карту "Номер строки -> Размерность".
Читает KNP (readKnp), создает кучу объектов TmRecord и кладет их в список records.
Ключевое слово: "Синглтон" (getInstance()). Данные хранятся в одном месте, доступны отовсюду.
2. "Где вы всё храните?" (Про однократное чтение)
Где: ru.uni.lab.service.DataService.
Поля:
List<TmRecord> records — тут вообще ВСЕ данные.
Map<Integer, List<TmRecord>> recordsByParam — тут данные, разбитые по кучкам (по параметрам). Чтобы быстро доставать.
Ответ: "Всё в памяти, в списках и мапах внутри DataService".
3. "Как парсится XML?" (Про рекурсию)
Где: ru.uni.lab.service.DataService, метод parseXmlRecursive.
Суть: Метод берет узел, читает атрибуты, а потом вызывает сам себя для всех дочерних узлов.
Ответ: "Рекурсивный обход DOM-дерева".
4. "Как строятся графики?"
Где: ru.uni.lab.ui.ChartPanel.
Как: Метод paintComponent.
Берет список записей.
Находит мин/макс значения (чтобы узнать масштаб).
В цикле рисует линии (g2.drawLine) от точки к точке.
Ответ: "Кастомная отрисовка через Graphics2D".
5. "Как работает список параметров слева?"
Где: ru.uni.lab.ui.ParameterListPanel.
Как: Использует JList и кастомный рендерер (ListCellRenderer), чтобы показывать не просто строку, а "ID: Имя".
6. "Как сделана таблица?"
Где: ru.uni.lab.ui.ValueTablePanel.
Как: Использует AbstractTableModel. Это "виртуальная" таблица. Она не хранит копии данных, а просто берет их из списка TmRecord, когда ей нужно отрисовать ячейку. Это экономит память.
7. "Как вы сделали этот лог с памятью?"
Где: ru.uni.lab.ui.LogPanel и DataService.
Как:
DataService пишет строки в список systemLog.
LogPanel берет этот список и выводит в текстовое поле.
Память считаем через Runtime.getRuntime().totalMemory().
8. "А как XML конкретного параметра выдергивается?"
Где: ru.uni.lab.ui.RawXmlPanel, метод doInBackground (внутри SwingWorker).
Как: Читает файл как строку -> ищет индекс number="ID" -> ищет назад <Param -> ищет вперед закрывающий тег. Вырезает кусок строки.
